# App flow
- O app deve ser um componente reutilizável em soluções Blazor
- Deve ser um projeto a parte que eu possa adicionar à uma solução
- Deve ser um componente com cores customizáveis
- Deve usar CSS puro
- Deve ser responsivo
- Deve solicitar o acesso a câmera
- Faça de uma forma que eu possa rodar uma demo para testar em meu celular pelo navegador
